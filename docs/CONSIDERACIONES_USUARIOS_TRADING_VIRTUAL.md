# 🎯 Consideraciones Importantes para Usuarios del Trading Virtual

## 📋 **Información General**

### ¿Qué es el Trading Virtual?
El sistema de trading virtual es una **plataforma de simulación** que permite a los usuarios practicar trading con datos de mercado reales pero con dinero virtual, sin riesgo financiero real.

## ⚠️ **Advertencias y Limitaciones**

### 🚨 **ADVERTENCIAS IMPORTANTES**

1. **NO ES TRADING REAL**
   - ❌ No se usa dinero real
   - ❌ No hay pérdidas financieras reales
   - ❌ No hay ganancias reales
   - ✅ Es solo para aprendizaje y práctica

2. **DATOS DE MERCADO REALES**
   - ✅ Los precios son reales de Yahoo Finance
   - ✅ Los movimientos de mercado son reales
   - ✅ La experiencia es similar al trading real
   - ⚠️ Pero las operaciones son simuladas

3. **PERSISTENCIA DE DATOS**
   - ✅ Los datos se guardan en tu navegador
   - ⚠️ Si borras los datos del navegador, perderás tu historial
   - ⚠️ Los datos no se sincronizan entre dispositivos

## 💰 **Sistema de Balance Virtual**

### Reglas del Balance Virtual

#### **Balance Inicial**
- 🎁 **$10,000 USD** para todos los usuarios registrados
- 💳 Se asigna automáticamente al primer acceso

#### **Reglas de Recarga**
- 🔒 **Solo se puede recargar** cuando el balance esté por debajo de **$100 USD**
- 💵 **Monto mínimo**: $1 USD
- 💵 **Monto máximo**: $10,000 USD
- ⏰ **Sin límite de recargas** (mientras se cumplan las reglas)

#### **Ejemplo de Uso**
```
Balance actual: $8,500 USD
→ No se puede recargar (está por encima de $100)

Balance actual: $75 USD
→ Se puede recargar entre $1 y $10,000 USD
```

## 📊 **Tipos de Órdenes Disponibles**

### 1. **Órdenes de Mercado (Market)**
- ⚡ **Ejecución inmediata** al precio actual
- 💰 **Sin garantía de precio** (puede variar)
- 🎯 **Ideal para**: Entradas rápidas

### 2. **Órdenes Límite (Limit)**
- 🎯 **Precio específico** de ejecución
- ⏳ **Puede no ejecutarse** si no se alcanza el precio
- 📈 **Compra**: Se ejecuta cuando el precio BAJA al nivel especificado
- 📉 **Venta**: Se ejecuta cuando el precio SUBE al nivel especificado

### 3. **Órdenes Stop**
- 🛑 **Activación por precio** específico
- 📈 **Stop de Compra**: Se ejecuta cuando el precio SUBE al nivel
- 📉 **Stop de Venta**: Se ejecuta cuando el precio BAJA al nivel

## 🛡️ **Gestión de Riesgo**

### Stop Loss y Take Profit
- 🛑 **Stop Loss**: Limita las pérdidas automáticamente
- 🎯 **Take Profit**: Cierra la posición en ganancia automáticamente
- ⚙️ **Configuración opcional** en cada orden

### Ejemplo de Gestión de Riesgo
```
Compra EURUSD a 1.0925
Stop Loss: 1.0900 (pérdida máxima: $250)
Take Profit: 1.0950 (ganancia objetivo: $250)
```

## 📈 **P&L y Rendimiento**

### Cálculo de P&L
- 💰 **P&L Absoluto**: Diferencia en dólares
- 📊 **P&L Porcentual**: Porcentaje de ganancia/pérdida
- ⏰ **Actualización en tiempo real** con precios de mercado

### Métricas de Rendimiento
- 📊 **Total P&L**: Suma de todas las posiciones
- 📈 **P&L Promedio**: Promedio por posición cerrada
- 🎯 **Tasa de Éxito**: Porcentaje de operaciones ganadoras
- ⚡ **Tasa de Llenado**: Porcentaje de órdenes ejecutadas

## 🔄 **Persistencia de Datos**

### ¿Qué se Guarda?
- 💰 **Balance virtual** y transacciones
- 📊 **Posiciones abiertas y cerradas**
- 📋 **Historial completo de órdenes**
- 📈 **P&L y métricas de rendimiento**

### ¿Dónde se Guarda?
- 🌐 **localStorage del navegador**
- 💻 **Específico del dispositivo**
- 🔒 **No se sincroniza** entre dispositivos

### Limitaciones de Almacenamiento
- 📏 **Límite**: ~5-10MB por dominio
- ⚠️ **Si se llena**: Puede afectar el funcionamiento
- 🧹 **Limpieza**: Los datos se mantienen hasta borrarlos manualmente

## ⚠️ **Problemas Comunes y Soluciones**

### Problema: "No puedo recargar mi balance"
**Solución**: Verifica que tu balance esté por debajo de $100 USD

### Problema: "Mis datos desaparecieron"
**Posibles causas**:
- Borraste los datos del navegador
- Cambiaste de dispositivo
- Limpiaste el caché

**Solución**: Los datos se reinician automáticamente

### Problema: "Las órdenes no se ejecutan"
**Verifica**:
- El tipo de orden (market, limit, stop)
- Los precios de mercado actuales
- La configuración de Stop Loss/Take Profit

### Problema: "El P&L no se actualiza"
**Solución**: Recarga la página para sincronizar con datos de mercado
